# 条件分支-if

if语句判断的定义：

- 如果 **条件满足**，才能做某件事情，
- 如果 **条件不满足**，就做另外一件事情，或者什么也不做
  正是因为有了判断，才使得程序世界丰富多彩，充满变化！
  **判断语句** 又被称为 “分支语句”，正是因为有了判断，才让程序有了很多的分支

> **Python程序语言指定任何非0和非空（null）值为true，0 或者 null为false。**

**Python 编程中 if 语句用于控制程序的执行，基本形式为：**

```python
if 判断条件：
    执行语句……
else：
    执行语句……
```

**用if语句组成一句话，可以这样理解：**

```python
如果 天气晴朗
    去室外散步
否则
    继续宅在家里
```

对比python语句中，**天气晴朗属于判断条件**，如果条件成立的话，***去室外散步***，不成立则在家。

在正式的使用之前我们还需要了解一下比较运算符

## if语句

在Python中，if语句允许我们根据一个条件或一组条件， 告诉计算机是否允许执行一组指令。

例子：

```python
math=100       #math是一个变量
if math==100:  #满足条件“true”    
    print(“恭喜你拿到了满分”)      #打印结果
```

## if-else语句

if-else语句根据`条件成立执行`语句，同样`条件不成立`也能执行相应的语句。

例子：

```python
math=100            # 判断变量是否为 100分
if math==100:       # 条件成立时设置标志为真     
    print(“恭喜你拿到了满分”)  # 并打印出信息 
else:                       # 条件不成立打印另一种结果    
    print(“继续加油”)

```

## if-elif语句

if 语句的判断条件可以用>（大于）、<(小于)、== (等于）、>=（大于等于）、<=（小于等于）来表示其关系。

当判断条件为***多个值***时，可以使用以下形式：

```python
if 判断条件1: 
   执行语句1…… 
elif 判断条件2:
   执行语句2…… 
elif 判断条件3:
   执行语句3…… 
else: 
   执行语句4…… 
```

例子：

```python
a = 15

if a > 10:
    print("a 的值大于 10")
elif a == 10:
    print("a 的值等于 10")
else:
    print("a 的值小于 10")
```

注意，`elif` 语句可以出现多次，用于检查多个条件。但是，`else` 语句只能出现一次，用于处理所有条件都不成立的情况。

# 逻辑运算符

逻辑运算符是python用来进行逻辑判断的运算符，虽然运算符只有and、or、not三种，但是理解这三个运算符的原理才是最重要的。

>   注意，Python 的 bool 逻辑运算符是 and、or、not，而非 &、||、~ (二进制位运算的逻辑与、或、非)。
>
>         以上说明的 and 及 or 的运算顺序都是 从左往右，但这都是在没有圆括号 “()” 和逻辑运算符混用的前提下的简单情况。
>             
>         如果存在更复杂的情况，则存在 运算优先级：() > not > and > or
> 

| 逻辑运算符 |      表达式      | 功能  |
| :---: | :-----------: | --- |
|  and  | x ***and*** y | 与运算 |
|  or   | x ***or*** y  | 或运算 |
|  not  |  ***not*** x  | 非运算 |

## and运算

```python
a = 5
b = 4
if a>0 and b>0:
    print("大于0")
else:
    print("小于0")
```

l两个条件都满足才输出结果“大于0”

## or运算

```python
a = 5
b = 4
if a>0 or b>0:
    print("大于0")
else:
    print("小于0")
```

两个条件有一个满足就输出“大于0”

## not运算

```
a = 0
if not a==1:
    print("你是对的")
```

条件"a== 1"不成立，但是有not运算将不成立变为了成立，所以最后输出结果为“你是对的”。
