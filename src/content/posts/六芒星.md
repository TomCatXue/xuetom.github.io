# 二、循环结构

> 循环结构是指在程序中需要反复执行某个功能而设置的一种程序结构。它由循环体中的条件，判断[继续执行](https://baike.baidu.com/item/继续执行/6359403?fromModule=lemma_inlink)某个功能还是退出循环。根据判断条件,循环结构又可细分为以下两种形式:先判断后执行的循环结构和先执行后判断的循环结构。

## for循环

> for循环是编程语言中一种循环语句，而[循环语句](https://baike.baidu.com/item/循环语句/4410586?fromModule=lemma_inlink)由[循环体](https://baike.baidu.com/item/循环体/5125491?fromModule=lemma_inlink)及循环的判定[条件](https://baike.baidu.com/item/条件/1783021?fromModule=lemma_inlink)两部分组成，其表达式为：for（单次表达式;条件表达式;末尾循环体）{中间循环体；}。

```
for i in range(a,b,c)
#a代表的是起始值
#b代表的是结束值
#c代表的是差值
结束值不包含在内
```

之前我们画正方形需要很多的代码，现在学了for循环以后只需三行：

```py
for i in range(0,4,1):
    t.forward(100)
    t.left(90)
```

# 三、六芒星

> 六芒星，也被称为大卫之星，是一个有六个尖角的六边形星形图案。

代码示例：

```
#六芒星
import turtle as t
t.pensize(3)
t.pencolor("yellow")
t.fillcolor("red")
t.begin_fill()
t.circle(100)
t.end_fill()
t.penup()
t.goto(-85,50)
t.pendown()
t.fillcolor("yellow")
t.begin_fill()
for i in range(3):
    t.forward(170)
    t.left(120)
t.end_fill()
t.penup()
t.goto(-85,150)
t.down()
t.fillcolor("yellow")
t.begin_fill()
for i in range(3):
    t.forward(170)
    t.right(120)
t.end_fill()
t.hideturtle()
t.done()
```
