**1、模拟算法**

> 用程序来模拟事物的发展，从而得到某种结果。本质上，是在程序中用变量模拟一些事物的状态，用一些语句和结构模拟事物的发展变化，利用计算机运行速度快的特点，达到某个问题的求解或得到某个答案

_写模拟算法的方法：_

就是理解下事物发展的规律，问题变化的特点，找出关键变化的量，用程序的变量来表示，同时理清楚用什么结构或者语句表示事物的发展变化，最终得出需要的结果

- 例题1：

【题目名称】开关灯

【题目描述】有n盏灯，编号为1~n。一开始所有的灯都是关着的。第1个人把所有灯开关按一下即打开了所有的灯，第2个人按下所有编号为2的倍数的开关（这些灯将被关掉），第3个人按下所有编号为3的倍数的开关（其中关掉的灯将被打开，开着的灯将被关闭），以此类推。一共有k个人，问最后有哪些灯开着？

【输入】一行两个整数n和k，表示有n盏灯和k个人，其中 1<=k<=n<=1000

【输出】按从小到大的顺序输出开着的灯编号

【样例输入】7 3 【样例输出】1 5 6 7

分析：

1、灯的状态

用数组a来表示灯状态，a[i]=1表示第i盏灯开着，a[i]=0表示第i盏灯关了

2、开关的操作

用 a[i]=1-a[i] 就可以表示将开关按一次

3、某一个人开关哪些灯

假如当前是第j个人，他能按的开关编号i需要满足：i%j==0

4、总共k个人

用循环结构表示k个人，编号j从1~k即可，同时每个人

```Cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int a[1005]={0},i,j,n,k;
    cin>>n>>k;
    for(j=1;j<=k;j++){
        for(i=1;i<=n;i++){
            if(i%j==0){
                a[i]=1-a[i];
            }
        }
    }
    for(i=1;i<=n;i++){
        if(a[i]==1){
            cout<<i<<" ";
        }
    }
    return 0;
}
```

- 例题2：

【题目名称】猴子选大王

【题目描述】有n只猴子选大王,猴子编号从1到n。现在让猴子从头到尾1~3开始报数，报到3的猴子退出，报至尾后，再从头接着报，同样是1~3报数，报到3的猴子退出，…，最后剩下的一只猴子即为大王。

【输入描述】现在输入n，求猴子大王的编号。

分析：

1、我们需要描述下猴子报数的形式，一个一个的往下报，报到最后再从前面接着来。这个我们可以用循环去一个一个座位的检查，如果有猴子就报数，没有就跳过

2、报数的时候，椅子上猴子的状态我们可以用一个数组visit表示，visit[i]=0表示第i个猴子还在椅子上，visit[i]=1表示第i只猴子不在椅子上，已经出去了，但是椅子还在

3、当前报的数我们需要记录下，报到3的猴子需要出去，即visit[i]=1,同时，记录下下一个猴子要报的数字

4、最后只要检查visit数组就知道猴子大王的编号了

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,visit[105]={0},num,i,k;
    cin>>n;
    num=n;
    for(i=0,k=1;n>1;i=(i+1)%num)
    {
        if(visit[i]==0)
        {
            if(k==3)
            {
                visit[i]=1;
                k=1;
                n--;
            }
            else
                k++;
        }
    }
    for(i=0;i<num;i++)
        if(visit[i]==0)
            cout<<i+1<<endl;
    return 0;
}
```
