彩虹彩虹，又称天弓（客家话）、天虹、绛等，简称虹，是气象中的一种光学现象， 当太阳光照射到半空中的水滴，光线被折射及反射，在天空上形成拱形的七彩光谱，由外圈至内圈呈红、橙、黄、绿、蓝、靛、紫 七种颜色。事实上彩虹有无数种颜色，比如，在红色和橙色之间还有许多种细微差别的颜色，但为了简便起见，所以只用七种颜色作为区别。

## 一、圆
> 圆的英文单词为：circle

```python
t.circle(a,b)  #a代表的是半径  b代表的是开合角度
```

通过代码我们可以画出任意弧度的圆，无论是半圆还是四分之一圆



可以看到我们画出的半圆它并不能向彩虹一样，所以我们需要用到方向去旋转，让方向朝上

```python
import turtle as t
t.left(90)  #将初始方向改变为向上
t.circle(100,180)
```

效果图：


有了彩虹的样子后，只需在添加好颜色

## 二、绘制彩色图形

为画笔加上颜色，使七种颜色都显示出

```python
t.pencolor(“red”)  #画笔颜色
```

也可以将画笔粗细进行调整

```python
t.pensize(10)  #画笔粗细 
```

在上述画出的半圆图形中，还带有小箭头，我们可以将画笔进行隐藏

```python
t.hideturtle() #画笔隐藏
```

## 三、坐标

> 仅仅是将一条半圆的颜色、大小进行调整也不是彩虹，我们需要将七条彩虹都绘画出来

这就需要用到坐标，将画笔位置进行移动

```python
t.goto(x,y) #将画笔移动到（x,y）的位置
```

移动完坐标后，会有墨迹残留，需要将笔抬起、落下

```python
t.penup()    #抬笔
t.pendown()  #落笔
```

## 四、实践

彩虹代码：

```python
#导入turtle库
import turtle as t
t.pensize(15)        #画笔粗细
#红色彩虹
t.left(90)
t.penup()
t.goto(100, -60)
t.pendown()
t.pencolor("red")    #画笔颜色
t.circle(100, 180)
#橙色彩虹
t.left(180)
t.penup()
t.goto(110, -60)
t.pendown()
t.pencolor("orange")    #画笔颜色
t.circle(110, 180)
#黄色彩虹
t.left(180)
t.penup()
t.goto(120, -60)
t.pendown()
t.pencolor("yellow")    #画笔颜色
t.circle(120, 180)
#绿色彩虹
t.left(180)
t.penup()
t.goto(130, -60)
t.pendown()
t.pencolor("green")    #画笔颜色
t.circle(130, 180)
#青色彩虹
t.left(180)
t.penup()
t.goto(140, -60)
t.pendown()
t.pencolor("cyan")    #画笔颜色
t.circle(140, 180)
#蓝色彩虹
t.left(180)
t.penup()
t.goto(150, -60)
t.pendown()
t.pencolor("blue")    #画笔颜色
t.circle(150, 180)
#紫色彩虹
t.left(180)
t.penup()
t.goto(160, -60)
t.pendown()
t.pencolor("purple")    #画笔颜色
t.circle(160, 180)
t.hideturtle()    #隐藏画笔
t.done()
```
