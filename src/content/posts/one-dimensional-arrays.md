**1、一维数组**

- 声明数组： 数据类型 数组名称[数组长度]；

```Cpp
int arr[10];
```

- 数组初始化：对一维数组进行赋值初始化；

```Cpp
int arr[5] = {1,2,3,4,5};   //初始化为对应的元素值
int arr[5] = {};   //所有数组元素都初始化为0
int arr[5] = {1};   //第一个元素为1，其余元素为0
int arr[5];  //系统随机分配一个数，数值不确定
```

- 数组下标：下标代表数组中的元素再数组中的位置，下标从0开始，并且没有负数，防止越界

```Cpp
int arr[5] = {1,2,3,4,5};
//下标：        0 1 2 3 4
```

例如：a[0]代表的数字为1。

3️⃣c++程序：

例题1：有N盏灯，开始时灯都是亮着的，每个灯都有一个开关控制着。现按其顺序编号为1,2,3，……N，然后将编号为2的倍数的灯拉一下，其次将编号为3的倍数的灯拉一下，再将编号为4的倍数的灯拉一下，最后将编号为5的倍数的灯拉一下，四次拉完之后，问亮着的灯的编号？

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int i,n;
    cin >> n;
    int a[n];
    for(i = 1; i <= n; i++){
        a[i] = 1;                 //亮
    }
    for(i = 1; i <= n; i++){
        if(i%2 == 0){
            a[i] = 1 - a[i];
        }
        if(i%3 == 0){
            a[i] = 1 - a[i];
        }
        if(i%4 == 0){
            a[i] = 1 - a[i];
        }
        if(i%5 == 0){
            a[i] = 1 - a[i];
        }
    }
    for(i = 1; i <= n; i++){
        if(a[i] == 1){
            cout << i << " ";
        }
    }
  return 0;
}
```

例题2：斐波那契数列

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int arr[47], i, k;
    cin >> k;
    arr[0] = 1;
    arr[1] = 1;
    for(i = 2; i < k; i++){
        arr[i] = arr[i-1] + arr[i-2];
    }
    cout << arr[k-1];
    return 0;
}
```
