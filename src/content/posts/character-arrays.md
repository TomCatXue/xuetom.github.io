2️⃣知识总结✅：

**1、字符数组的定义**

```Cpp
char c[100];
```

**2、字符数组的初始化**

```Cpp
char c1[100]='adadlal';
char c2[200]={'e','d','a'};
```

**3、字符数组的输入**

|   |   |   |
|---|---|---|
|**格式**|**说明**|**举例**|
|cin>>字符数组名;|输入一行字符串到字符数组中，但是碰见空格、制表符或者换行会终止|char c[10];cin>>c;|
|cin.getline(字符数组名,长度,结束标记)|输入一行字符串到字符数组中，碰到结束标记才终止。结束标记可以省略，如果省略，则是碰到换行符就终止|char c[10];cin.getline(c,10);|
|gets(字符数组名)|输入一行字符串到字符数数组中，碰到换行符就终止。但这个函数需要加头文件“cstdio”|char c[10];gets(c);|

**4、字符数组的输出**

|   |   |   |
|---|---|---|
|格式|说明|举例|
|cout<<字符数组名;|依次输出字符数组中的元素值，直到碰到’\0’结束标记|char c[10]=“abc\0ef”;cout<<c;//屏幕显示“abc”|
|puts(字符数组名)|依次输出字符数组中的元素值，直到碰到’\0’结束标记，并且把碰到的’\0’转化为’\n’输出。但这个函数需要加头文件”cstdio”|char c[10]=“abc\0ef”;puts(c);//屏幕显示“abc”并换行|

3️⃣c++程序

【题目名称】数字统计

【题目描述】输入一串字符串，分别统计其中数字字符0、1、2、· · ·、9出现的次数

【输入】一行一个字符串，字符串长度不超过255

【输出】输出10个整数，即0、1、2、…、9出现的次数，每个整数之间用一个空格隔开

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    char s[300]=" ";
    int i,num[10]={0};
    gets(s);
    for(i=0;i<300;i++){
        if(s[i]>='0'&& s[i]<='9'){
            num[s[i]-'0']++;
        }
    }
    for(i=0;i<10;i++){
        cout<<num[i]<<" ";
    }
}
```

【题目名称】小写转大写

【题目描述】输入一串字符（长度小于100），将其中的小写字母转换成大写，其他不变，再输出

【输入】一行字符串

【输出】输出转换后的字符串

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    char c[105]=" ";
    cin.getline(c,105);
    for(int i=0;i<105;i++){
        if(c[i]>='a'&&c[i]<<'z'){
            c[i] -= 32;
        }
    }
    cout << c;
    return 0;
}
```
