# 象棋

 	象棋，亦作“象碁”、中国象棋，中国传统棋类益智游戏，在中国有着悠久的历史，属于二人对抗性游戏的一种，由于用具简单，趣味性强，成为流行极为广泛的棋艺活动。中国象棋是中国棋文化也是中华民族的文化瑰宝。
 	
 	中国象棋是起源于中国的一种棋戏，象棋的“象”是一个人，相传象是舜的弟弟，他喜欢打打杀杀，他发明了一种用来模拟战争的游戏，因为是他发明的，很自然也把这种游戏叫做“象棋”。到了秦朝末年西汉开国，韩信把象棋进行一番大改，有了楚河汉界，有了王不见王（即白脸将），名字还叫作“象棋”，然后经过后世的不断修正，一直到宋朝（宋朝人用词不喜欢重复），把红棋原来的“炮”改为“砲”、“卒”改为“兵”：黑棋的“仕”改为“士”，“相”改为“象”，象棋的样子基本完善。棋盘里的河界，又名“楚河汉界”。

# 二、write()函数

> write(arg,move=False，align,font=（“Arial”，8，“normal”）)

- arg：需要写入的文字，需用“”标注，不可单独放置到（）内部

- move：move默认为False，如果move=Ture，文字移到文本右下角

- align：文字的对齐方式，需用=连接，=后面需用 “ ” 标

  ​          （居中（center）左对齐（left）右对齐（right））

- font：font=（fontname，fontsize，fonttype）

  ​     fontname--字体类型

  ​     fontsize--字体大小

  ​     fonttype--字体样式

示例：

```python
import turtle as t
t.write("你好", align="right", font=("宋体", 20, "normal"))
t.done()
```

arg = “你好”   align=右对齐

 # 三、象棋棋盘

代码：

```python
import turtle as t
t.pensize(2)      # 设置画笔粗细
t.speed(5)      # 设置画笔移动速度
t.bgcolor("orange")     #设置背景颜色
#画横线
for i in range(10):
    t.penup()
    t.goto(0, i*40)
    t.pendown()
    t.forward(320)
#画竖线
t.right(90)
for i in range(9):
    t.penup()
    t.goto(i*40,360)
    t.pendown()
    t.forward(360)
#长方形覆盖
t.penup()
t.goto(0, 160)
t.pendown()
t.fillcolor("orange")
t.begin_fill()
t.left(90)
t.forward(320)
t.left(90)
t.forward(40)
t.left(90)
t.forward(320)
t.left(90)
t.forward(40)
t.end_fill()
#画斜线
t.penup()
t.goto(120, 0)
t.pendown()
t.goto(200,80)
t.penup()
t.goto(200, 0)
t.pendown()
t.goto(120,80)
t.penup()
t.goto(120, 360)
t.pendown()
t.goto(200,280)
t.penup()
t.goto(200, 360)
t.pendown()
t.goto(120,280)
#标注汉字
t.penup()
t.goto(60, 165)
t.write("楚河", align="center", font=("宋体", 20, "normal"))
t.penup()
t.goto(260, 165)
t.write("汉界", align="center", font=("宋体", 20, "normal"))
t.hideturtle()      #隐藏画笔
t.done()
```
