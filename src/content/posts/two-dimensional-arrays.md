2️⃣知识总结✅：

**1、二维数组的声明**

类型明 数组名 [行长度]  [列长度]

二维数组的总元素个数：行的长度*列的长度

```Cpp
int a[2][3];
```

**2、二维数组的初始化**

- 方法一：分行赋初值

**int a[2][3]={{1,2,3},{4,5,6}};**

**int b[4][3]={{1,2,3},{},{4,5}};**

- 方法二：顺序赋初值

**int a[2][3]={1,2,3,4,5,6};**

**int b[4][3]={1,2,3,0,0,0,4,5};**

- 方法三：部分元素赋初值(行长度可省，列长度不可省)

**int a[][3]={1,2,3,4,5,6,7};**

**int b[][4]={{1}，{4,5}};**

- 建议最好的赋值方法：清晰明了，方便观察

```C++
int a[2][3] ={ {1,6,3},
            {4,5,6}
              };
```

例题1：

【题目名称】对角元素的和

【题目描述】输入一个 n*n 的整数矩阵，求这个矩阵中，两条所有对角线上的元素和。对角线上的元素就是相当于在一个方形的矩阵中，画对角线，对角线经过的元素

【输入】第一行一个整数n，表示矩阵的大小，接下来是n行，每行n个整数，其中 0<n<=100，每个整数也在-100到100之间

【输出】一行一个整数，即对角元素的和

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int a[105][105],i,j,n,sum=0;
    cin>>n;
    for(i=0;i<n;i++){
        for(j=0;j<n;j++){
            cin>>a[i][j];
        }
    }
    for(i=0;i<n;i++){
        sum=sum+a[i][i];
    }
    for(i=0;i<n;i++){
        sum=sum+a[i][n-1-i];
    }
    if(n%2==1){
        sum=sum-a[n/2][n/2];
    }
    cout<<sum<<endl;
    return 0;
}
```

例题2：

【题目名称】杨辉三角

【题目描述】

杨辉三角是数学上非常有名的求二项式系数的数字序列。它的特点是：第i行有i个数，每行的第一个数和最后一个数都是1，其他的每个数等于该数的上一行同一列的数加上上一行前一列的数的和。

现在输入一个n，请输出对应的杨辉三角前n行的数

【输入】一行一个正整数n

```Cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int a[105][105],i,j,n;
    cin>>n;
    for(i=0;i<n;i++)
    {
        a[i][0]=1;
        a[i][i]=1;
        for(j=1;j<i;j++)
            a[i][j]=a[i-1][j]+a[i-1][j-1];
    }
    for(i=0;i<n;i++)
    {
        for(j=0;j<=i;j++)
            cout<<a[i][j]<<" ";
        cout<<endl;
    }
}
```
