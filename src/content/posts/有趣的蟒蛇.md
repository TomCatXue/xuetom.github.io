# 有趣的蟒蛇

## 一、初识Python

Python 是一种解释型、面向对象、动态数据类型的高级程序设计语言。

Python 由 Guido van Rossum 于 1989 年底发明，第一个公开发行版发行于 1991 年。

像 Perl 语言一样, Python 源代码同样遵循 GPL(GNU General Public License) 协议。

特点：

- **Python 是一种解释型语言：** 这意味着开发过程中没有了编译这个环节。类似于PHP和Perl语言。
- **Python 是交互式语言：** 这意味着，您可以在一个 Python 提示符 **>>>** 后直接执行代码。
- **Python 是面向对象语言:** 这意味着Python支持面向对象的风格或代码封装在对象的编程技术。
- **Python 是初学者的语言：**Python 对初级程序员而言，是一种伟大的语言，它支持广泛的应用程序开发，从简单的文字处理到 WWW 浏览器再到游戏。

## 二、Turtle库

python中的turtle库，又叫做画笔海龟，是python中专门画图的一个工具库。在使用时我们要先将其导入，然后才能进行代码的编写！

首先我们来导入turtle库，也就是我们的画笔海龟库。

在python中有专用的代码，来进行各种库的导入，以下为导入turtle库的代码：

```
import turtle as t
```

import 导入；引进

## 三、几何图形应用

用turtle画出几何图形，从简单的正方形开始：

首先，我们需要让计算机知道画图时的逻辑,万事万物都有逻辑可言，做好一件事情，顺序很重要；

> 例如，把一个大象装进冰箱需要三个步骤：
>
> - 第一步：打开冰箱门
> - 第二步：把大象装进冰箱
> - 第三步：关住冰箱门

在画笔海龟中我们也存在这样的顺序：

> - 第一步：导入画笔海龟库
> - 第二步：用方法去画几何图形
> - 第三步：结束画图

```
import turtle as t #导入海龟库
t.前进
t.转弯
t.前进
t.done()  #画图完成
```



画笔海龟中我们还要了解向前、向后、向左、向右的单词：

``` 
forward()  # 向前
backward() # 向后
left()     # 向左
right()    # 向右
```

## 四、实践

正方形：向前->转弯->向前

注意前进后退中的的单位是像素

```
import turtle as t
t.shape('turtle') #形状为海龟
t.forward(100)  # 向前走100
t.left(90)  # 向左转90度
t.forward(100)  
t.left(90) 
t.forward(100)  
t.left(90) 
t.forward(100)  
t.left(90) 
t.done # 结束
```
