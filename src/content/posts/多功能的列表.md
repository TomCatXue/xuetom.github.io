# 多功能的列表

## 一、list列表

## 1、概述

> list列表的本质是一种***有序***的集合

## 2、列表的用法

```python
语法： 列表名 = [元素1，元素2，元素3…]

说明：列表中的选项被称为元素，跟string类似，下标也是从0开始计数
```

例子：

```python
#创建空列表
list1 = []
list1 = list()#格式化

#创建带有元素的列表
list2 = [10, 20, 30, 10]
print(list2)
#结果
[10, 20, 30, 10]
#在列表中元素的数据类型可以不同（灵活性）表中的元素类型可以是任意python中的基本数据类型或者是自定义的数据类型
list3 = [33, "good", True, 10.32]
print(list3)
#结果
[33, 'good', True, 10.32]
```

## 二、列表元素增删改查

## 1、查找

> 功能：访问list列表中元素值
>
> 语法：列表名[索引]
>
> list1[index]
> index取值范围[0,len(list1))
>
> len（list）表示列表的长度

例子：

```python
list4 = [22, 33, 12, 32, 45]
#下标从0开始，最大值为len(list4)-1
print(list4[0])
#结果
22
```

 **列表的下标元素是从0开始，依次往后推**

>  当下标超过元素个数-1时，程序会出错

```python
print(list4[5])
IndexError: list index out of range
```

**通过下标区间去查找列表元素**

> 使用下标索引来访问列表中的值，同样你也可以使用方括号 **[]** 的形式截取字符，如下所示：

```python
nums = [10, 20, 30, 40, 50, 60, 70, 80, 90]
print(nums[0:4])
#结果
[10, 20, 30, 40]
```

负数索引值也可以进行查询，只是会从元素末尾值开始

## 2、更新列表

> 替换列表中的某一元素
>
> 语法：列表名[下标] = 值
>
> list1[index] = 值

例子：

```python
list4 = [22, 33, 12, 32, 45]
list4[0] = "hello"
print(list4)
#结果
['hello', 33, 12, 32, 45]
```

## 3、增加列表

- 增加单个元素或单个列表

> 在列表中末尾添加新的元素【在原本的列表中追加元素】
>
> 需用到append（）函数，append()中的值**可以**是**列表**也可以是**普通元素**



例子：

```python
list1 = [3, 4, 6]
list1.append(6)
print(list1)
>>>[3, 4, 6, 6]
```

- 在末尾一次性增加追加另外一个列表中的多个值

> 功能：在列表的末尾一次性追加另外一个列表中的多个值
>
> 注意：extend()中的值**只能**是**列表/元组**[一个可迭代对象(可加在for循环之后的)]，打碎可迭代对象之后的元素再加入列表中，**不能**是元素

## 4、插入元素

- list.insert(下标值, 元素/列表)

> 功能：在下标处插入元素，不覆盖原本的数据，原数据向后顺延
>
> 注意：插入的数据可以是元素也可以为列表

```python
list1 = [1,2,3]
list1.insert(1,0)
print(list1)
>>>[1, 0, 2, 3]
list1.insert(1,[2, 4, 8])
print(list1)
>>>[1, [2, 4, 8], 0, 2, 3]
```

## 5、移除元素

- list.pop(下标值)

> 功能：移除列表中指定下标处的元素(默认移除最后一个元素)，并**返回**移除的数据
>
> 注意此处会返回删除数据

```python
>>> list1 = [1, [2, 4, 8], 0, 2, 3]
>>> list1.pop()
3
>>> print(list1)
[1, [2, 4, 8], 0, 2]
>>> list1.pop(2)
0
>>> print(list1)
[1, [2, 4, 8], 2]

```

- list.remove(元素)

> 移除列表中的某个元素第一个匹配结果

```python
list1 = [1, 2, 3]
list1.remove(2)
print(list1)
>>>[1, 3]

```

- **del语句**

> 可以使用 del 语句来删除列表的的元素

```python
list = ['Google', 'Runoob', 1997, 2000] 
print ("原始列表 : ", list)
del list[2]
print ("删除第三个元素 : ", list)
```

## 6、清除列表

- list.clear()清除列表中所有的数据

  ```python
  >>> list1 = [1, 2, 3]
  >>> list1.clear()
  >>> print(list1)
  []
  ```
