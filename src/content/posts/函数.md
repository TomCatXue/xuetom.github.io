# 一、函数的定义

> 函数是组织好的，可重复使用的，用来实现单一，或相关联功能的代码段。
>
> 函数能提高应用的模块性，和代码的重复利用率。你已经知道Python提供了许多内建函数，比如print()。但你也可以自己创建函数，这被叫做用户自定义函数。

# 二、创建函数

函数其实就是我们Scratch语言中的自制积木，它的意义在于`可重复使用`，从而可以去进行代码的简化和精简。

在创建函数时，需要有一定的规则:

1. 函数代码块以 **def** 关键词开头，后接函数标识符名称和圆括号**()**。
2. 任何传入参数和自变量**必须**放在圆括号中间。圆括号之间可以用于定义参数。
3. 函数的第一行语句可以选择性地使用文档字符串—用于存放函数说明。（可不添加）
4. 函数内容以冒号起始，并且缩进。
5. **return [表达式]** 结束函数，选择性地返回一个值给调用方。不带表达式的return相当于返回 None(空)。

例子：

```python
def printme( str ):
   "打印传入的字符串到标准显示设备上"
   print(str)
   return
```

# 三、调用函数

和Scratch语言中一样，函数也需要被调用才能使用，否则无意义。

创建函数只是给函数名称和参数以及结构体，具体的使用还需要参数去进行调用。

例如，刚才我们已经定义了printme()函数，但是参数str是没有的，那我们需要进行参数传递：

```python
printme("哇哇哇!")
printme("哈哈哈哈")
```

这样才会有结果表示：

```python
哇哇哇!
哈哈哈哈
```
