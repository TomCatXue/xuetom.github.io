
# 一、基本概念

> 贪心算法是在解决问题时总是做出当前最优选择，通过局部最优解来推导出全局最优解的方法。

贪心算法与汉诺塔、递推递归、回溯、二分等算法不同，它没有固定的算法框架，而是一种解决问题的思想。

需要注意的是，贪心算法并不能解决所有问题的最优解。

# 二、基本思路

1. 建立数学模型来描述问题
2. 把求解问题分成若干个子问题
3. 对每一个子问题进行求解，得到局部的最优解
4. 把所有子问题的解合并成最终问题的解

# 三、适用问题

前提：局部最优策略能导致产生全局最优解

# 四、实现框架

从问题的某一个初始解出发：

```Cpp
while(能朝着给定总目标前进一步){
	利用可行的决策，求出可行解的一个解元素；
}//由所有解元素组合成问题的一个解
```

# 五、典型例题

例1：排队打水问题

有n个人排队到r个水龙头去打水，他们装满水桶的时间t1,t2,…,tn为整数且各不相等，应如何安排他们的打水顺序才能使他们花费的总时间最少？

每个人打水的时间 = 排队的时间 + 实际打水的时间，本题假设一个人打好水，排在他后面的人接着打水的这个切换过程不消耗时间。

比如，有2个人A和B，他们打水的时间分别是3和2，只有1个水龙头，这时，如果A先打水，B后打水，那么A和B打水的时间分别为3、3+2（B排队3分钟）。

因此，所有人打水的总时间就是每个人的打水时间及每个人的排队时间的总和。

**用例输入 1**

```Cpp
4 2
2 6 4 5
```

**用例输出 1**

```Cpp
23
```

代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[510], n, r, sum;
int main(){
	cin >> n >> r;
	for (int i = 1; i <= n; i++) {
		cin >> a[i];
	}
	sort(a+1, a+n+1);
	for (int i = 1; i <= n; i++) {
		if (i >= r+1) {              //解决子问题
			a[i] += a[i-r];
		}
		sum += a[i];                 //合并子问题最优解
	}
	cout << sum;
}
